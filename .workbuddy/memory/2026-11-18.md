### 操作教训（PowerShell）

`git -C $src diff HEAD --output=(Join-Path $dir $n) -- <file>` **不行**：PowerShell 会把 `--output=(...)` 拆成 `--output=` 空路径参数，git 报 `could not open '' for writing`，而且我同一条命令里的 `restore` 已经把工作区改动清掉了，只能重做一遍编辑。正确写法：`$arg = '--output=' + $path; git -C $src diff HEAD $arg -- <file>`。**先单独验证导出语法，再写"导出 + 还原"的串联命令。**
