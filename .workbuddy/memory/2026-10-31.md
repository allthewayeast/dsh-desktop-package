# 2026-10-31

## DSH Next：新增 DSH_WEB_PORT（可控监听端口）

### 端口原本从哪来

- 设置页 `port` → `desktop-preferences.json` → 主进程 `desktop-runtime.ts` 以
  `DSH_NEXT_PREFERENCES` 注入 → `host/index.ts` 的 `preferences.port`（默认 0 = 系统分配）。
- `host/index.ts` 用它两处：runtime patch 的 `desktop-next-webserver.config.port`，以及
  `runProfile({ args: ['--no-open','--port', String(...)] })`。**没有环境变量入口**，这是本次补的。

### 实现

- `overlay-next/patches/index.ts.patch`（源码侧，4 hunk）：新增 `parseWebPortEnv`，端口三态：
  未写 → `preferences.port`；写 `0` → 强制系统分配；写 1–65535 → 用它。非法值启动即抛
  `Invalid DSH_WEB_PORT: expected an integer from 0 through 65535`。两处使用点都换成 `webPort`，
  并打一行 `hostLog({ event: 'web.listen.plan', fields: { host, port, portSource } })`。
- `overlay-next/src/startup-config.ts`：白名单从三个 `DSH_*` 扩到四个（加 `DSH_WEB_PORT`）。
  spec 的 web-access 用例同步加断言 → 16/16 通过。
- `build-next.ps1`：
  - `OverlayPatchesRequireListenAllNetwork` → `OverlayPatchesRequireWebAccess`，门控从
    「只给 listen」改成「任一 Web 访问开关」—— 端口与 host 共用同一份源码补丁，
    只固定端口、不开通配时给 `-FixedTokenPatch` 就够。
  - 标记字典 `RequiredMarkersWhenListenPatch` → `RequiredMarkersWhenWebAccess`
    （`lib/host.js` 断言 `DSH_NEXT_WEB_HOST` + `DSH_WEB_PORT`），`Requires` 新增 `web` 类；
    `lib/main.js` 常态标记加 `DSH_WEB_PORT`（白名单字面量）。
  - 计划/收尾文案：端口写进 startup.json 样例；`Get-DshWebAccessStartupGuide` 加端口行。
- 文档：`BUILD_GUIDE.md` 新增「端口：`DSH_WEB_PORT` 怎么生效」（三态表 + 设置页仍显示偏好值）、
  参数说明、覆盖层表格、`quick-build-next.bat` 帮助。

## 监听地址改名：DSH_NEXT_WEB_HOST → DSH_WEB_HOST（无兼容层）

- 命名理由：上游 `DSH_NEXT_*` 全是「主进程注入、host 读完即删」的内部通道
  （`DSH_NEXT_PREFERENCES` / `DSH_NEXT_TRUSTED_HOSTS` / `DSH_NEXT_NATIVE_TOKEN`），
  而这是用户手写进 `startup.json` 的配置，应归入 `DSH_WEB_` 族（同名族还有
  `DSH_WEB_TOKEN` / `DSH_WEB_PORT` / `DSH_WEB_TRUSTED_HOSTS`，以及上游的
  `DSH_WEB_URL` / `DSH_WEB_SEARCH_PROVIDER`）。`DSH_WEB_HOST` 在上游全仓未被占用。
- 用户明确要求**不做兼容**：先加了 `legacyWebHostEnv` 回退 + stderr deprecated 提示，
  随后按要求删除。旧名现在**完全不识别**，写了会静默回落到 `127.0.0.1` —— 这一点已写进
  `BUILD_GUIDE.md`（升级时要手动改名已部署的 startup.json）。
- 改动点：`overlay-next/patches/index.ts.patch`（重新从工作区 diff 生成，
  `const webHost = process.env.DSH_WEB_HOST?.trim() || '127.0.0.1'`）、
  `startup-config.ts` 白名单删掉旧名、spec 删掉 deprecated 用例（17→16）、
  `build-next.ps1` / `tools/dsh-web-access.ps1` / `BUILD_GUIDE.md` / `quick-build-next.bat` 全文替换。
- 验证：完整构建 `[01]`–`[17]` 通过，`lib/host.js` 与 `lib/main.js` 各命中 `DSH_WEB_HOST` 1 次、
  `DSH_NEXT_WEB_HOST` 0 次；`process.env.DSH_WEB_HOST?.trim() || "127.0.0.1"` 编译产物可读；
  单测 16/16。
